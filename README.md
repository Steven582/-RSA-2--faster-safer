# -RSA-2--faster-safer
第二代RSA加密算法演示程序，包含素数生成 密钥生成 加密 解密的全过程，用筛法随机选取的5位数素数，以及拓展欧几里得法求d，并使用快速幂进行加密解密。The second-generation RSA encryption algorithm demonstration program covers the entire process of prime number generation, key generation, encryption, and decryption. It randomly uses the extended Euclidean algorithm to calculate, and employs the fast power method .
